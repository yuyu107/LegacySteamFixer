# test15 本批修改记录

基于 0.4.0-test14；用户已于 2026-10-18 授权与游戏管理菜单一起打包发布为 test15。

- 自动检查更新不再弹窗或排队弹窗；右上角更新按钮显示“有更新”，蓝色突出，悬停可见新版本号。
- 手动检查发现新版同样只更新按钮和状态提示；用户再次点击并选择查看后才打开发行说明与下载界面。
- 诊断/日志窗口使用非模态单窗口，可与主界面并行操作；重复点击激活已有窗口。
- 诊断信息与实时日志分为两个页签，默认显示实时日志；操作进行中仍可查看日志。
- 新日志实时追加；可关闭自动滚动，保留旧日志的选择范围和垂直滚动位置。
- 诊断刷新在后台操作期间禁用，使用操作前快照，避免遍历正在修改的游戏/配置集合；导出附上当前日志。

已通过主程序编译。窗口交互、按钮提示和 Win7 显示效果仍需下一批实机测试。

- Steam 工具区新增“重新检测 Steam”，重新读取注册表和常见安装位置，检测后刷新游戏列表。
- 检测必须找到 steam.exe，跳过仅目录残留的安装记录，支持注册表 SteamExe 值及默认路径回退。
- 启动或刷新时无有效目录不再抛出错误弹窗，而在主界面引导下载、手动选择目录或重新检测；暂停 Zstd 操作并清除旧游戏列表。
- 手动选择会校验所选目录包含 steam.exe；自动检测失败时保留已经手动选中的有效目录。
- 下载入口沿用现有官方页面，并提示仍需使用兼容的旧版客户端。
- 已通过编译及候选目录检测测试；Windows 注册表和实际布局仍待实机验证。

- Zstd 模块以独立返回值区分首次启用和当前 Steam 进程已启用；提权运行的 Fixer 同样保留该结果。
- 重复应用时显示“补丁已启用，无需重复应用”，状态栏和日志不再误报为首次应用成功；仅 Steam 完全退出或重启后需要再次启用。
- 已重新构建模块并同步组件哈希，已验证成功/重复/失败结果及提权结果序列化；真实 Steam 重复应用仍待实机验证。

- 游戏右键及更多菜单、进程身份核对、Steam 卸载和可验证的修补清理，见 RELEASE_NOTES.md。
